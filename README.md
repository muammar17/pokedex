# Pokedex App

Aplikasi web untuk melihat daftar Pokemon dan detailnya menggunakan data dari PokeAPI.

## Tech Stack

- React 16.8.6
- Redux + Redux Saga
- React Router DOM
- Axios
- Bootstrap 5.3.8
- PrimeReact 10.9.8
- Styled Components
- Webpack 4

## Features

- Menampilkan list Pokemon dengan lazy loading / infinite scroll
- Detail Pokemon (stats, types, abilities)
- Pencarian/filter Pokemon
- Responsive design

## Quick Start

### Prerequisites

- Node.js >= 8.15.1
- npm >= 5

### 5 Langkah Menjalankan Project:

1. **Clone repository**
   ```bash
   git clone <repository-url>
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Masuk ke directory project**
   ```bash
   cd pokedex
   ```

4. **Jalankan development server**
   ```bash
   npm start
   ```

5. **Buka browser**
   Aplikasi akan berjalan di `http://localhost:3000`
